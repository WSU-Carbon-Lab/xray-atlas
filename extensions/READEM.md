# X-ray Atlas Extensions

Here we store all the extension modules as their own git submodules within this folder

## CLI
The command line interface for the application. Very minimal with just a few core features

## Igor
A updated version of Eliot Gann's QANT tool that has atlas connections to load
data directly into the application, and to upload data back to the atlass when done

## Python
A python package to provide similar funcitonality as hugging face but for NEXAFS data

## VS Code
A VS Code extension to provide a data browser and graphical interface for the application

## Zed
A Zed extension to provide a data browser and graphical interface for the application
